# About This Site

## macOS Portfolio Website

Welcome to my personal portfolio website, designed to simulate the macOS experience right in your browser!

### Design Philosophy

This website is built to replicate the familiar and intuitive macOS interface, providing visitors with an engaging and interactive way to explore my work and background. The design focuses on:

- **Authenticity**: Faithful recreation of macOS UI elements and interactions
- **Usability**: Intuitive navigation that feels natural to Mac users
- **Performance**: Smooth animations and responsive design
- **Accessibility**: Ensuring the site is usable by everyone

### Technical Implementation

The site is built using modern web technologies:

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS, UnoCSS
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Deployment**: Netlify/Vercel

### Features

- 🖥️ **Desktop Environment**: Complete macOS desktop simulation
- 📱 **Responsive Design**: Works on all device sizes
- 🎵 **Audio Integration**: Background music and sound effects
- 📁 **File System**: Simulated file browser and applications
- 🌙 **Dark/Light Mode**: Toggle between themes
- 🔍 **Spotlight Search**: Quick navigation and search functionality

### Applications

The portfolio includes several "applications" that showcase different aspects of my work:

- **Bear**: Markdown-based blog and project documentation
- **Safari**: Web browser simulation with bookmarks
- **Terminal**: Command-line interface with custom commands
- **Finder**: File system browser
- **Photos**: Image gallery and portfolio pieces

### Inspiration

This project was inspired by the excellent work of developers who have created similar macOS simulations on the web. It represents my passion for both frontend development and attention to detail in user experience design.
